# Studio intro + loading screen kit (Ottran Studios)

A drop-in studio intro (~2.8 s) and loading screen for every Ottran Studios game: a Godot 4 addon
(`addons/studio_intro/`) and a web version for three.js games (`studio_intro_web/`).
The brand (studio name, wordmark, colours, font, jingle, logo files) lives in ONE file:
`addons/studio_intro/brand.json`. Everything else is generic, so the kit can be re-branded in minutes.

**The beat:** the jelly mascot drops in (stretch), lands with a big squash, hops into its letter slot (it IS the
"O" of OTTRAN), wiggles. The letters pop in one by one with overshoot, STUDIOS rises in under them, the mascot does
a happy hop with a sparkle, and the logo fades into the game. A cheerful synthesized jingle plays in sync.
Tap to skip after 0.5 s. Portrait, landscape, any aspect ratio, safe-area aware.

Godot 4.3 to 4.7 (tested on 4.3-stable and 4.7.2-stable), gl_compatibility safe. Everything is drawn with vector
CanvasItem calls: no textures at runtime (memory is about 0 MB of textures plus the MSDF font atlas and a 35 KB ogg).

## What's in the folder

| `addons/studio_intro/fonts/` | Fredoka Bold (static, overlaps removed for clean MSDF), OFL licence |
| `addons/studio_intro/audio/jingle.ogg` | original jingle, generated by code (numpy synth), 2.8 s |
| `addons/studio_intro/brand/` | logo.png (transparent, trimmed), logo_bg.png (2048x1024), mark.png (512, mascot): for stores, web, press |
| `addons/studio_intro/plugin.cfg` | optional editor plugin: enabling it adds the StudioLoader autoload |

| `tools/preview.sh` | render preview MP4/GIF + key frames into `preview/` |

| `preview/` | intro MP4 + GIF (portrait 1080x2400, landscape 2400x1080), key frames, web shots |

## Godot integration (about 5 minutes)

1. Copy `addons/studio_intro/` into your project's `addons/`.
2. Add the autoload: Project Settings, Autoload, `StudioLoader` = `res://addons/studio_intro/studio_loader.gd`
   (or enable the "Studio Intro" plugin, which adds it).
3. Set the main scene to `res://addons/studio_intro/studio_intro.tscn` and add to `project.godot`:
   ```ini
   [studio_intro]
   next_scene="res://scenes/main.tscn"      ; your old main scene
   hold_loader=false                       ; true = keep the loading screen up until your scene calls StudioLoader.end()
   loader_theme="res://data/loader_theme.json"
   audio_bus="SFX"                         ; optional: play the jingle on your SFX bus (your volume slider applies)
   ```
4. Export preset: add `addons/studio_intro/*.json` to "Filters to export non-resource files"
   (brand.json is read with FileAccess). Optional: exclude `addons/studio_intro/brand/*` (store art, not used at runtime).
5. Optional: set `application/boot_splash/bg_color` to the brand `bg_top` (#FFF7E8) so boot, splash and intro blend.

### Loading screen API
```gdscript
StudioLoader.load_scene("res://level.tscn", ["Tip one", "Tip two"])   # threaded load + bar + change scene
await StudioLoader.cover()            # show it (procedural builds, reload_current_scene, ...)
await StudioLoader.step(0.5)          # report progress and draw one frame (instant no-op when not covering)
StudioLoader.set_progress(0.8)
await StudioLoader.end()              # waits out the 0.4 s minimum, then fades (returns when the fade starts)
StudioLoader.end(false)               # no minimum: use this in online play so nothing ever waits on the overlay
StudioLoader.configure({"tips": [...], "colors": {...}, "layer": 52})
```
Theme JSON keys: `tips`, `title`, `colors` (`bg_top`, `bg_bottom`, `bar`, `bar_bg`, `bar_outline`, `title`, `tip`,
`bokeh`), `mascot` (colour overrides), `layer` (CanvasLayer, default 120), `min_display` (0.4), `max_cover` (45 s watchdog).

Games that build their world in `_ready()` (like Crumbellion): set `hold_loader=true`, call `await StudioLoader.step(p)`
between the heavy build steps and `await StudioLoader.end()` before you reveal the game.

### Other ways to run the intro
- From code: `StudioIntro.play_then("res://game.tscn")` (optional `hold` argument).
- As an overlay: instance `studio_intro.tscn` with `next_scene = ""`, await `finished` (it frees itself).

### Lifecycle
Backgrounded during the intro: it freezes (jingle paused) and fades straight into the game on return. Android back
skips it. The loading screen keeps its threaded load running; a watchdog hides it after `max_cover` seconds if the
game never calls `end()`.

## Web / three.js integration
```html
<script src="studio_intro_web/brand.js"></script>
<script src="studio_intro_web/intro.js"></script>
<script>
  const ld = StudioIntro.loader({tips: ["Tip one"], colors: {bg_top: "#E8F6FF", bg_bottom: "#B9E2FF"}});
  const ready = StudioIntro.trackThree(THREE.DefaultLoadingManager, ld);   // resolves on manager.onLoad
  StudioIntro.play({ready, loader: ld}).then(startGame);   // intro, then the loader until `ready`, then the game
</script>
```
Options for `play`: `ready` (promise), `loader`, `skipAfter` (0.5), `sound` (true; browsers may block autoplay, then
the intro is silent), `volume`, `base` (asset folder), `zIndex`. `loader(...)` returns `{show, setProgress, done}`.
Open `studio_intro_web/index.html` for a demo.

## Re-branding (new name or colours)
1. Edit `addons/studio_intro/brand.json` (`studio_name`, `wordmark`, `subline`, `colors`, optional `mascot_slot`:
   `"auto"` = the mascot replaces the last O/o/0, a letter index, or `"above"` for a mascot above the wordmark).
2. Run `DISPLAY=:97 PREVIEW=1 tools/make_brand.sh` (about 9 s without the preview, about 2.5 min with it). It rebuilds
   the jingle (one note per letter), `studio_intro_web/brand.js`, the logo PNGs and, with PREVIEW=1, the preview.
   `FONT=1` also rebuilds the static font from `tools/font_src/Fredoka-Variable.ttf`.
3. Copy `addons/studio_intro/` into each game again (keep the game's own `.import` files) and re-import.
   An all-caps wordmark gets letter spacing automatically.

Needs: python3 with numpy (fonttools + skia-pathops only for FONT=1), ffmpeg, ImageMagick, Godot 4.3+ and an
X display (Xvfb). Fonts: Fredoka, SIL Open Font License (fonts/OFL.txt). Jingle and art: original, made by code.
